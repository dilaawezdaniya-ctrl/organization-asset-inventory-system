# User Requirements

## Organization Admin

- Can add departments
- Can edit departments
- Can view departments

## Inventory Manager

- Can add departments
- Can edit departments
- Can view departments

## Department Head

- Can view department information
- Can view department assets
- Cannot add or edit departments

## IT Staff

- Can view department information
- Cannot add or edit departments

## Asset Requirements

- Asset ID
- Asset Name
- Serial Number (optional)
- Category
- Department
- Location
- Purchase Date
- Purchase Price
- Condition
- Status

## IT Security Requirements

For applicable IT assets:

- Firewall status
- Antivirus status
- Operating System
- Last security check
- Overall security status
